# Week 4 - Products and Frameworks (Part 2)
## Spring REST using Spring Boot 3 & Code Quality with SonarQube

This folder contains hands-on exercises for Week 4 of the DN 5.0 Deep Skilling program.

### Topics Covered:
1. **Spring REST using Spring Boot 3**
   - RESTful Architecture
   - REST Controllers
   - HTTP Methods (GET, POST, PUT, DELETE)
   - Request/Response Handling
   - Data Transfer Objects (DTOs)
   - CRUD Operations
   - HATEOAS
   - Content Negotiation
   - Spring Boot Actuator
   - Security with Spring Security
   - API Documentation with Swagger

2. **Code Quality and SonarQube**
   - SonarQube Architecture
   - Static Code Analysis
   - Integration with Maven
   - Code Quality Metrics
   - Quality Gates

### Exercises:
- `spring_rest/` - REST API examples with controllers and DTOs
- `sonarqube/` - SonarQube configuration and analysis examples
