# Week 3 - Products and Frameworks (Part 1)
## Spring Core with Maven & Spring Data JPA with Spring Boot

This folder contains hands-on exercises for Week 3 of the DN 5.0 Deep Skilling program.

### Topics Covered:
1. **Spring Core and Maven**
   - Spring Framework Overview
   - IoC Container and Dependency Injection
   - Bean Configuration (XML, Annotations, Java-based)
   - Spring AOP (Aspect-Oriented Programming)
   - Spring MVC
   - Spring Boot Introduction

2. **Spring Data JPA with Spring Boot**
   - Entity Mapping with JPA
   - Spring Data Repositories
   - CRUD Operations
   - Query Methods
   - Pagination and Sorting
   - Hibernate Integration

### Exercises:
- `spring_core/` - Spring Core examples with IoC, DI, AOP
- `spring_jpa/` - Spring Data JPA examples with entities and repositories
- `pom.xml` - Maven configuration for Spring dependencies
