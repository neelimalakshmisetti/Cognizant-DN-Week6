# Week 1 - Engineering Concepts
## Design Patterns and Principles & Data Structures and Algorithms

This folder contains hands-on exercises for Week 1 of the DN 5.0 Deep Skilling program.

### Topics Covered:
1. **Design Patterns and Principles**
   - SOLID Principles
   - Creational Patterns (Singleton, Factory Method, Builder)
   - Structural Patterns (Adapter, Decorator, Proxy)
   - Behavioral Patterns (Observer, Strategy, Command)

2. **Data Structures and Algorithms**
   - Algorithm Analysis (Time/Space Complexity)
   - Sorting Algorithms (Bubble, Quick, Merge Sort)
   - Arrays and Linked Lists
   - Searching Algorithms (Linear, Binary Search)

### Exercises:
- `solid_principles/` - SOLID principles implementation examples
- `design_patterns/` - Common design pattern implementations
- `data_structures/` - Array, Linked List implementations
- `algorithms/` - Sorting and searching algorithms
- `complexity_analysis/` - Time and space complexity examples
