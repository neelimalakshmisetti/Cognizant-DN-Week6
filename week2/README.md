# Week 2 - Programming Languages
## PL/SQL Programming & Test Driven Development with Logging Framework

This folder contains hands-on exercises for Week 2 of the DN 5.0 Deep Skilling program.

### Topics Covered:
1. **PL/SQL Programming**
   - PL/SQL Block Structure
   - Variables and Data Types
   - Control Structures (IF-THEN-ELSE, Loops)
   - Exception Handling
   - Cursors (Implicit and Explicit)
   - Stored Procedures and Functions
   - Packages
   - Triggers

2. **Test Driven Development (TDD)**
   - TDD Cycle (Red-Green-Refactor)
   - JUnit 5 Framework
   - Mockito for Mocking
   - Test Structure (AAA Pattern)
   - Parameterized Tests

3. **Logging Framework**
   - SLF4J Introduction
   - Lombok Annotations
   - Logging Levels

### Exercises:
- `plsql/` - PL/SQL scripts and procedures
- `tdd/` - JUnit 5 and Mockito test examples
- `logging/` - SLF4J and Lombok logging examples
