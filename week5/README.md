# Week 5 - Products and Frameworks (Part 3)
## Microservices with Spring Boot 3 and Spring Cloud

This folder contains hands-on exercises for Week 5 of the DN 5.0 Deep Skilling program.

### Topics Covered:
1. **Microservices Architecture**
   - Microservices vs Monolithic
   - Microservices Principles
   - Service Discovery
   - API Gateway
   - Circuit Breaker Pattern
   - Inter-Service Communication

2. **Spring Cloud Components**
   - Spring Cloud Config
   - Netflix Eureka (Service Discovery)
   - Spring Cloud Gateway
   - Spring Cloud Circuit Breaker
   - Spring Cloud Feign
   - Centralized Authentication with OAuth2/JWT

3. **Microservices Security**
   - Spring Security for Microservices
   - OAuth2 and OIDC
   - JWT Tokens
   - Inter-service security

### Exercises:
- `microservices/` - Microservice examples with Eureka, Gateway, and Config
- `security/` - OAuth2 and JWT implementation examples
