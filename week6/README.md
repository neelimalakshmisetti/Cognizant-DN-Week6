# Week 6 - Products and Frameworks (Part 4)
## React Single Page Application & Application Debugging

This folder contains hands-on exercises for Week 6 of the DN 5.0 Deep Skilling program.

### Topics Covered:
1. **React Single Page Application**
   - Introduction to SPA
   - React Components (Functional and Class)
   - JSX and ES6
   - Props and State
   - React Events
   - Conditional Rendering
   - Lists and Keys
   - React Forms
   - API Integration (Fetch and Axios)

2. **Application Debugging**
   - Chrome DevTools
   - React DevTools
   - VS Code Debugger
   - Breakpoints and Watch Variables
   - DOM Inspection
   - Network Tab
   - Console Debugging

### Exercises:
- `react/` - React component examples with forms and API integration
- `debugging/` - Debugging examples and techniques
