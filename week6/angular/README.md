# Angular Hands-on Exercises

A comprehensive set of Angular exercises covering components, services,
routing, HTTP client, reactive forms, and state management.

## Prerequisites
```bash
npm install -g @angular/cli
ng version   # Verify Angular CLI
```

## Exercises Overview
| File | Topic |
|---|---|
| `app.component.ts` | Root component & bootstrapping |
| `employee.component.ts` | Smart & presentational components |
| `employee.service.ts` | Services & Dependency Injection |
| `app.routes.ts` | Angular Router setup |
| `http-client.service.ts` | HTTP Client & RxJS |
| `reactive-form.component.ts` | Reactive Forms & Validation |
| `auth.guard.ts` | Route Guards |
| `employee.pipe.ts` | Custom Pipes |
