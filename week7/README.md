# Week 7 - Platforms & GenAI
## Version Control, DevOps, Cloud, and Generative AI

This folder contains hands-on exercises for Week 7 of the DN 5.0 Deep Skilling program.

### Topics Covered:
1. **Version Control - GIT**
   - Git commands and workflows
   - Branching and merging
   - Remote repositories
   - Pull requests and collaboration

2. **DevOps and CI/CD**
   - Continuous Integration
   - Continuous Deployment
   - CI/CD tools (Jenkins, GitHub Actions)

3. **Containerization - Docker**
   - Docker commands
   - Docker images and containers
   - Docker Compose
   - Docker networking

4. **Cloud Fundamentals**
   - AWS services (EC2, S3, RDS, Lambda)
   - Cloud concepts and deployment models

5. **Agile Methodology**
   - Scrum framework
   - User stories and estimation
   - Sprint planning

6. **GenAI Fundamentals**
   - Generative AI concepts
   - Prompt engineering
   - GitHub Copilot
   - Context engineering

### Exercises:
- `git/` - Git workflow examples
- `docker/` - Dockerfile and docker-compose examples
- `cloud/` - AWS service examples
- `genai/` - Prompt engineering and GitHub Copilot examples
